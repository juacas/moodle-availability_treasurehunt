# availability_treasurehunt 1.0.6

This stable release improves handling of availability conditions that refer to a Treasure Hunt stage that is missing, deleted, or belongs to another activity. Such conditions now evaluate as **false**. Teachers see a configuration warning, while students see a clear message that the required stage is unavailable.

The CI workflow is synchronized with the main Treasure Hunt plugin. See [CHANGELOG.md](CHANGELOG.md) for the release history.
